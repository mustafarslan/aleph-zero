# Privacy

Aleph Zero, its engine and its Claude Code plugin collect no data and send none to the author or to any service.

- Your code, the index, the vectors and the memories stay on your machine, in the places the README lists under
  [Where data lives](README.md#where-data-lives).
- The plugin's side chat sends your question and excerpts of the matching code to Claude through Claude Code's own model
  connection, as any Claude Code request does; Anthropic's terms for Claude Code apply to it.
- The network is used only when you ask: to download language grammars, the embedding model and the llama.cpp source,
  and repositories you link by URL. See [What it runs, sends and fetches](README.md#what-it-runs-sends-and-fetches).

There is no telemetry, no account and no server operated by the author.
