# Security

Please report a vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/mustafarslan/aleph-zero/security/advisories/new),
not in a public issue. Include what you ran, what happened, and the output of `aleph-zero --version`.

What Aleph Zero does on your machine is listed in the README under
[What it runs, sends and fetches](README.md#what-it-runs-sends-and-fetches).
